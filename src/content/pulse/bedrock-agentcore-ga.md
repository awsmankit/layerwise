**What changed.** AWS made Bedrock AgentCore generally available on 13 October 2025, after a preview in July. It is a set of separate pieces for running agents: a session-isolated runtime, memory, a gateway that turns APIs and Lambda functions into MCP tools, identity, code interpreter and browser sandboxes, and OpenTelemetry-based observability.

**Why it matters.** Each of the three big clouds now sells a managed agent runtime. The hard parts are still yours: tool permissions, limits and evals.

**What to do.** Compare the three clouds' agent runtimes in the [cloud AI map](../../learn/cloud/cloud-ai-service-map/), and read [Agents and tool use](../../learn/rag-agents/agents-and-tool-use/) before you pick one.
