**What changed.** Microsoft announced at Ignite in November 2025 that Azure AI Foundry is now Microsoft Foundry. It was Azure AI Studio before that. Microsoft's product terms use the new name from January 2026, and some built-in roles were renamed too.

**Why it matters.** Endpoints and keys for existing deployments carried on working, but documentation, SDK samples and role names now differ between older and newer material.

**What to do.** Check that your access policies use the current role names, and search for all three names when troubleshooting. See [Microsoft Foundry and Azure OpenAI](../../learn/cloud/microsoft-foundry-and-azure-openai/).
