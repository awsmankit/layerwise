A model's weights are numbers. Training usually keeps them in 16 or 32 bits each. **Quantization** stores them with fewer bits, such as 8 or 4, and maps them back to useful values during computation. The model gets smaller and, because generation is limited by memory bandwidth, usually faster. The cost is some loss of precision.

## The memory arithmetic

Weight memory is parameters times bytes per parameter. For an 8-billion-parameter model:

| Format | Bytes per parameter | Approximate weights |
|---|---|---|
| FP32 | 4 | 32 GB |
| BF16 or FP16 | 2 | 16 GB |
| INT8 | 1 | 8 GB |
| INT4 | 0.5 | 4 GB |

Real files are slightly larger because of scales and other metadata. Change the precision below and compare with device memory.

## What can be quantized

- **Weights.** The most common choice, and the safest big win.
- **Activations.** The intermediate values during computation. Harder, because their range varies with the input.
- **The KV cache.** Storing keys and values in 8 bits cuts the cache in half. See the previous lesson.

## How it is done

**Post-training quantization (PTQ)** converts an already-trained model. Methods such as GPTQ and AWQ are smarter about which weights matter most, and so lose less accuracy at 4 bits. A small calibration set of representative inputs is typically used.

**Quantization-aware training (QAT)** simulates low precision during training so the model learns to be robust to it. It is more work and generally gives better quality at very low bit widths.

Simple rounding uses a **scale factor**: the largest weight sets how far apart the allowed levels are. Try it below with eight example weights, one of them unusually large.

## What to check before you ship one

1. **Run your own eval suite on both versions.** Public benchmark results do not tell you how your task behaves.
2. **Look at the tails.** Averages can hide degradation on long contexts, rare languages, maths or code.
3. **Measure speed on the target hardware.** Gains depend on the chip supporting the format with efficient kernels. A format the hardware cannot execute natively may run no faster.
4. **Compare against a smaller model at higher precision.** Sometimes a smaller model in 8 bits beats a larger one in 3 or 4.

<Callout title="A good default">
8-bit weights usually cost very little quality. 4-bit weights are widely used and often fine, but test them. Below 4 bits, expect to need quantization-aware techniques and careful checking.
</Callout>
